# western-theme README

## 0.1
### test describtion(work is still in progress)

This extension aims to:

1. **Reduce eye strain** caused by overly bright color themes, especially those with harsh, oversaturated colors.
2. **Improve concentration while working** by combining a calm, dark background with light foreground colors and bright terminal colors.
3. **Provide comfortable syntax highlighting.** The syntax colors are not perfect yet, as the theme is still in development. However, for now, I would describe them as calm and balanced, with cyan accents for highlighting important elements.

**Main color palette:** yellow, white, cyan, green, and purple.

Together, these colors create a Western atmosphere that helps you stay focused on important elements while keeping everything else calm and easy to understand.
